# NETRIVA POKER PRO · Онлайн маса

Texas Hold'em (8-max) за реални играчи през браузър. Node.js + Socket.IO.
Свободните места се допълват от ботове с рационал. Provably-fair тесте:
SHA-256 печат преди раздаването, разкриване на server seed след ръката.

## Какво има вътре
```
server.js        — сървърът: стаи, енджин, ботове, честност
public/index.html — клиентът (масата в браузъра)
package.json
```

## 1. Пробвай локално (по избор)
Нужен е Node.js 18+ (https://nodejs.org).
```
npm install
npm start
```
Отвори http://localhost:3000 в два различни браузъра/таба — създай маса
в единия, влез с кода в другия.

## 2. Качи кода в GitHub
1. Регистрирай се на https://github.com (безплатно).
2. Създай нов repository, напр. `netriva-poker`.
3. Качи файловете (`server.js`, `package.json`, папката `public/`)
   през бутона "Add file → Upload files" — без `node_modules`.

## 3. Пусни го онлайн в Render (безплатен план)
1. Регистрирай се на https://render.com (може с GitHub акаунта).
2. New → **Web Service** → свържи GitHub → избери `netriva-poker`.
3. Настройки:
   - Runtime: **Node**
   - Build command: `npm install`
   - Start command: `npm start`
   - Instance type: **Free**
4. Create Web Service. След 1–2 минути получаваш адрес от типа
   `https://netriva-poker.onrender.com`.

Изпрати линка на приятелите. Първият създава маса и получава 5-буквен код
(или директно копира линка за покана от бутона горе вдясно — кодът е в него).
Останалите въвеждат името си и кода.

Бележка за безплатния план на Render: услугата "заспива" след ~15 минути
без посетители и първото отваряне после отнема ~30–60 секунди. За вечер
покер с приятели това не пречи — след събуждането всичко е нормално.
Алтернативи със сходна процедура: Railway (railway.app), Fly.io (fly.io).

## Как се играе
- Всеки играч на масата може да пуска "Нова ръка" и да променя общите
  настройки (блайндове, стек, скорост и режим на ботовете). Всяка промяна
  се обявява в дневника с името на този, който я е направил.
- По подразбиране ботове допълват масата до пълни 8 места.
- Всеки играч има 45 секунди на ход; после авто-check/fold.
- При разкачване играчът се fold-ва и мястото се освобождава след ръката.
- Историята на ръцете показва всички действия + рационала на ботовете.
- Client seed: всеки може да запише свой seed в Настройки — той влиза
  в комбинирания client seed за HMAC разбъркването от следващата ръка.

## Честност (provably fair)
Преди раздаването сървърът публикува SHA-256 печат на server seed-а.
Тестето = HMAC-SHA256(server seed, combined client seed + ":" + номер на ръката),
после Fisher–Yates с небиасирани байтове. След ръката seed-ът се разкрива
и всеки може да провери, че печатът съвпада (бутонът "Провери" в панела).

## Важно
Играта е с виртуални чипове, за развлечение между приятели.
Не е предназначена за игра с реални пари.
